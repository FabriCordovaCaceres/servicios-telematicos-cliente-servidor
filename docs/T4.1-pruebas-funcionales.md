**Tarea:** T4.1
**Arquitectura:** Cliente-Servidor
**Requerimiento:** RQ13 — Pruebas funcionales
**Rama:** `sprint4-t4.1-pruebas-funcionales-cs`
**Fecha de verificación:** 03/11/2026

## 1. Objetivo

Verificar el funcionamiento del prototipo Cliente-Servidor mediante pruebas funcionales sobre las operaciones de creación, consulta, actualización y eliminación de tareas, incluyendo la validación de datos incorrectos y la sincronización de eventos mediante WebSocket.

## 2. Entorno de pruebas

- Lenguaje: TypeScript y JavaScript.
- Entorno de ejecución: Node.js.
- Framework del servidor: Express.
- Protocolo REST: HTTP.
- Comunicación en tiempo real: WebSocket.
- Servidor REST: `http://localhost:3000/tasks`.
- Servidor WebSocket: `ws://localhost:3000/ws`.
- Herramientas: VS Code, PowerShell y Node.js Test Runner.

Las pruebas se realizaron sobre el servidor ejecutado localmente.

## 5. Defectos identificados y correcciones

Durante la revisión funcional se identificaron dos defectos relacionados con la eliminación de tareas:

**Defecto 1: Invocación de la eliminación.** Se identificó que la ruta DELETE necesitaba comprobar correctamente el resultado de la función `deleteTask()`. La ruta fue revisada y se verificó su funcionamiento.

**Defecto 2: Eliminación del almacenamiento.** El servicio notificaba la eliminación, pero no retiraba realmente la tarea del arreglo en memoria. Se corrigió incorporando `tasks.splice(index, 1)`.

Posteriormente, las pruebas confirmaron que una tarea eliminada deja de aparecer en la lista y que su consulta devuelve HTTP 404.

## 8. Alcance y limitaciones

Las pruebas comprobaron el comportamiento funcional del prototipo en un entorno local. El almacenamiento de tareas se realiza en memoria.

Las pruebas WebSocket utilizaron dos clientes. Estos resultados no constituyen una validación de escalabilidad, seguridad o tolerancia a fallos, aspectos que corresponden a otras tareas del Sprint 4.
